# Pochampelly Manikanta — Portfolio

Responsive portfolio built strictly with HTML5 and CSS3. No JavaScript and no CSS frameworks.

## Included
- `index.html` — semantic page structure, navigation, experience flowcharts, education showcase, certificate gallery and CSS-only lightboxes.
- `style.css` — design, responsive layouts, flowchart connectors, certificate gallery and CSS interactions.
- `assets/` — portrait, event photographs, resume, and three supplied certificate PDFs with image previews.

## Run
Keep the folder structure unchanged and open `index.html` in a browser. For deployment, upload the complete folder to a static host.

## Certificate interactions
Click a certificate preview to open its full-size image in a CSS-only `:target` lightbox. Each card also links to the original PDF.

## Syllabus alignment
Semantic HTML, navigation anchors, headings, paragraphs, ordered lists, images and alt text, links, CSS selectors, pseudo-classes, box model, typography, colour, Flexbox, Grid, positioning and responsive media queries.
